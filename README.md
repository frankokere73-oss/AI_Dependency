# AI_Dependency
AI Depndency, Career Anxiety and Student Burnout

The rapid rise of generative AI tools such as ChatGPT, Claude, Gemini, and GitHub Copilot has fundamentally changed how students learn, complete assignments, prepare for placements, and develop professional skills. Alongside these opportunities, students now face increasing concerns related to automation, career uncertainty, academic pressure, burnout, and dependency on AI-assisted workflows.
